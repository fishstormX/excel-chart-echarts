# Example workbooks

Native Excel charts used in the README / [more-examples](../docs/more-examples.md) gallery.  
Convert locally:

```bash
excel-chart-echarts examples/line-chart.xlsx -j -o out.json
# or
xlsx2echarts examples/combo-secondary-axis.xlsx -o out/
```
